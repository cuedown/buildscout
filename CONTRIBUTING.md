# Contributing

Thanks for helping make project-car planning less expensive and less mysterious.

## Ground rules

- Prefer structured, verifiable compatibility data over anecdotes.
- Cite sources in comments or PR descriptions for factual fitment claims.
- Do not add scrapers that bypass access controls or violate provider terms.
- Keep core planning features available without payment.
- Never commit API tokens, cookies, passwords, wallet seed phrases, or private keys.

## Pull requests

Keep PRs focused. Explain the user problem, the change, how you tested it, and any source/provider constraints.
